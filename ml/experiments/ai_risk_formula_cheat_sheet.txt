--------------------------------------------------------
1. MEAN / AVERAGE
--------------------------------------------------------

Formula:

mean = sum of all values / number of values

Mathematical form:

mean = Σx / n

Where:
- Σx = sum of all values
- n = number of values

Example:

Values = [250, 800, 120]

sum = 250 + 800 + 120 = 1170
n = 3

mean = 1170 / 3
     = 390

NumPy:

np.mean(amounts)


--------------------------------------------------------
2. DEVIATION FROM THE MEAN
--------------------------------------------------------

Formula:

deviation = value - mean

Example:

Values = [250, 800, 120]
Mean = 390

For 250:

250 - 390 = -140

For 800:

800 - 390 = 410

For 120:

120 - 390 = -270

NumPy:

deviation = amounts - np.mean(amounts)


--------------------------------------------------------
3. RELATIVE VALUE COMPARED WITH AN AVERAGE
--------------------------------------------------------

Formula:

relative value = value / average

Example:

Amount = 250
Average amount = 125.5

relative value = 250 / 125.5
               ≈ 1.992

Interpretation:
The transaction amount is approximately 1.992 times the average amount.

NumPy:

relative_amount = amounts / average_amounts


--------------------------------------------------------
4. RELATIVE DEVIATION
--------------------------------------------------------

Formula:

relative deviation = (value - average) / average

Example:

Amount = 250
Average = 125.5

relative deviation = (250 - 125.5) / 125.5
                   ≈ 0.992

If expressed as a percentage:

percentage deviation = ((value - average) / average) × 100

Example:

0.992 × 100 ≈ 99.2%


--------------------------------------------------------
5. STANDARD DEVIATION
--------------------------------------------------------

Population standard deviation formula:

σ = sqrt( Σ(x - μ)^2 / n )

Where:
- σ = standard deviation
- x = each value
- μ = mean
- n = number of values
- Σ = sum

Step-by-step:

1. Calculate the mean.
2. Calculate each value's deviation from the mean.
3. Square each deviation.
4. Add the squared deviations.
5. Divide by n.
6. Take the square root.

For our values:

[250, 800, 120]

Mean = 390

Deviations:

250 - 390 = -140
800 - 390 = 410
120 - 390 = -270

NumPy:

np.std(amounts)

IMPORTANT:
np.std() uses the population standard deviation by default (ddof=0).


--------------------------------------------------------
6. VARIANCE
--------------------------------------------------------

Population variance formula:

variance = Σ(x - μ)^2 / n

Standard deviation is the square root of variance:

standard deviation = sqrt(variance)

Therefore:

variance = (standard deviation)^2

NumPy:

np.var(amounts)

11. PERCENTILE
--------------------------------------------------------

A percentile describes a position within ordered data.

The 50th percentile corresponds to the median.

Example:

[120, 250, 800]

50th percentile = 250

NumPy:

np.percentile(amounts, 50)


--------------------------------------------------------
12. NUMPY DEFAULT LINEAR PERCENTILE POSITION
--------------------------------------------------------

For NumPy's default percentile method (method="linear"), the position is:

position = (n - 1) × p

Where:
- n = number of values
- p = percentile expressed as a decimal

Examples:

25th percentile:

p = 25 / 100
  = 0.25

For:

[120, 250, 800]

n = 3
p = 0.25

position = (3 - 1) × 0.25
         = 2 × 0.25
         = 0.5

So the percentile lies at position 0.5.

IMPORTANT:
NumPy uses zero-based positions for this calculation.

Positions:

position 0 → 120
position 1 → 250
position 2 → 800


--------------------------------------------------------
13. LINEAR INTERPOLATION FOR PERCENTILES
--------------------------------------------------------

When the percentile position is not a whole number, interpolate between
the surrounding values.

General formula:

result = lower_value + fraction × (upper_value - lower_value)

For our 25th percentile:

Values:

[120, 250, 800]

Position = 0.5

Lower value = 120
Upper value = 250
Fraction = 0.5

Therefore:

result = 120 + 0.5 × (250 - 120)
       = 120 + 0.5 × 130
       = 120 + 65
       = 185

Therefore:

25th percentile = 185.0

NumPy:

np.percentile(amounts, 25)


--------------------------------------------------------
14. PERCENTILE AS A PERCENTAGE
--------------------------------------------------------

Convert a percentage to a decimal:

p = percentage / 100

Examples:

25% = 25 / 100 = 0.25
50% = 50 / 100 = 0.50
75% = 75 / 100 = 0.75
90% = 90 / 100 = 0.90
95% = 95 / 100 = 0.95
99% = 99 / 100 = 0.99


--------------------------------------------------------
15. IMPORTANT PERCENTILE NAMES
--------------------------------------------------------

25th percentile = Q1 = first quartile

50th percentile = Q2 = median

75th percentile = Q3 = third quartile

We will use Q1 and Q3 later when learning IQR and outlier detection.


--------------------------------------------------------
16. IQR — INTERQUARTILE RANGE
--------------------------------------------------------

Formula:

IQR = Q3 - Q1

Where:
- Q1 = 25th percentile
- Q3 = 75th percentile

Example structure:

Q1 = 25th percentile
Q3 = 75th percentile

IQR = Q3 - Q1

We will calculate this with actual transaction data when we reach the
outlier-detection section.


--------------------------------------------------------
17. OUTLIER BOUNDARIES USING IQR
--------------------------------------------------------

Common rule:

Lower boundary = Q1 - 1.5 × IQR

Upper boundary = Q3 + 1.5 × IQR

A value below the lower boundary or above the upper boundary is commonly
flagged as a potential outlier.

IMPORTANT:
This is a statistical rule of thumb, not a guarantee that a value is
fraudulent or risky. We will use it as a feature-engineering technique.


--------------------------------------------------------
18. TRANSACTION AMOUNT INCREASE BY A PERCENTAGE
--------------------------------------------------------

To increase a value by r%:

new value = original value × (1 + r)

where r is written as a decimal.

Example:

10% = 0.10

new amount = amount × 1.10

For:

[250, 800, 120]

new values:

[250 × 1.10, 800 × 1.10, 120 × 1.10]

= [275, 880, 132]

NumPy:

amounts * 1.10


--------------------------------------------------------
19. PERCENTAGE CHANGE
--------------------------------------------------------

Formula:

percentage change = ((new value - old value) / old value) × 100

Example:

Old value = 100
New value = 120

percentage change = ((120 - 100) / 100) × 100
                 = 20%

This will become useful when we work with transaction behavior changes.

--------------------------------------------------------

For a 2D NumPy array:

shape = (number of rows, number of columns)

Example:

[[250, 3, 125.5],
 [800, 8, 400.25],
 [120, 1, 80]]

There are:

3 rows
3 columns

Therefore:

shape = (3, 3)

NumPy:

transactions.shape

21. NUMBER OF ELEMENTS IN AN ARRAY
--------------------------------------------------------

For a NumPy array:

size = total number of elements

For a 3 × 3 matrix:

size = 3 × 3
     = 9

NumPy:

--------------------------------------------------------
22. NUMBER OF DIMENSIONS
--------------------------------------------------------

For a NumPy array:

ndim = number of dimensions

Examples:

[100, 200, 300]

ndim = 1

A matrix such as:

[[100, 200],
